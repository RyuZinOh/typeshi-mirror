## typeShi - A Typing Application

![typeShi](./application/assets/typeShi.svg)
1. Installation: `paru -Syu typeshi`
2. This depends on matugen to generate the theme and read/apply it for now, so u have to install matugen and follow this [template](https://github.com/RyuZinOh/.dotfiles/blob/main/matugen/templates/typeshi.ini) and generate on `~/.config/typeShi/config.ini`
3. For Development/Contribution -> follow the clang-format i guess.
